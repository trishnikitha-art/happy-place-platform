### 3. HPP Responsibilities

**Constitutional Ownership:**

**Business Objects:**
- Project - Canonical source of truth for all project data
- Customer - Canonical source of truth for customer information
- Estimate - Canonical source of truth for estimate data
- Task - Canonical source of truth for task definitions
- Photo - Canonical source of truth for media assets
- Invoice - Canonical source of truth for billing data
- Crew - Canonical source of truth for crew assignments
- Warranty - Canonical source of truth for warranty information
- Inspection - Canonical source of truth for inspection data

**Why:** These are core business entities. Their meaning, structure, and relationships are constitutional to the business domain. PING can reference them but cannot define or own them.

**Events:**
- EventEnvelope - Canonical event structure schema
- DomainEvent - Canonical domain event definitions
- Event Definitions - Canonical event type definitions (EstimateCreated, CrewAssigned, etc.)
- Event Implementations - Generated event implementations

**Constitutional Law:** Events are never handwritten. Only generated. Exceptions forbidden. No temporary exceptions. No migration exceptions.

**Why:** Events are the constitutional source of truth for state transitions. Their schema, types, and meanings must be owned by the platform to ensure determinism and replayability.

**Replay:**
- Replay Engine - Canonical replay logic
